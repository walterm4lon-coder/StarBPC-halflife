## What is it?
This is starbie, my digital pet, that can react to the enviroment using a scensor. He can be scared, chill, sleep, or be played with or fed!
its based on XIAO ESP32-C3 and has a tiny OLED display,environmental sensor, and interactive buttons.

## Features
animated pixel cat: https://last-tick.itch.io/animated-pixel-kittens-cats-32x32
interactive Menu: NAP, PLAY, FEED, and PET.
motion detector
environmental sensors
custom PCB

## Hardware:
XIAO ESP32-C3, SSD1306 128×64 OLED, MPU6050, DHT11, 2 push buttons, custom PCB
